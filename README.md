# Quadranti per Amazfit Active 2

Galleria: https://ubiquint.github.io/amazfit/

Ogni quadrante ha un QR `zpkd1://…` da scansionare con l'app Zepp in **Modalità sviluppatore**
(Profilo → il tuo orologio → in fondo → Modalità sviluppatore → Scansiona).
Il QR punta al pacchetto `.zip` del quadrante pubblicato su GitHub Pages.
